NormaCode Portfolio (v10)
Deploy on GitHub Pages:
1. Create a PUBLIC repo named exactly: norma-bazzi.github.io
2. Upload index.html, favicon.svg and the media folder (drag the folder itself) to the top level.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Open https://norma-bazzi.github.io/ after 1-2 minutes.
Notes:
- Contact details and links: search for CFG near the top of the script in index.html.
- Menu Demo live link: https://norma-bazzi.github.io/Menu-demo/
- Needs internet for fonts and the 3D library.
